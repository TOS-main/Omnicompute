What do "direct" and "relay" mean?

Direct: the device sends its work straight to the next device (hole-punched UDP). Fastest.

Relay: its traffic goes through the main computer, which forwards it. It works on any network (school Wi-Fi, cellular), but each token takes a little longer. Browsers (phones, Chromebooks) always use the relay for now.

Standby: connected, but the mesh is currently faster without it (an extra hop costs more than it saves). Turn on "Always use" to include it anyway.

On another network or cellular

        
Start the main computer with edgemesh host --public (or answer "yes" to the question in the launcher). It prints an https link and QR code that work from any network, with no router setup. This page then shows that link. https also turns on the GPU in phone and Chromebook browsers.

        
Other ways besides Cloudflare
          
Tailscale (free, recommended for your own devices): install it on the main computer and each device, sign in with the same account, and they share a private network that works across Wi-Fi, school and cellular. Use the main computer's Tailscale address (100.x.y.z) in the link. Devices even connect directly, so it's faster than a tunnel. Tailscale Funnel can also give a public https address.

          
ngrok: ngrok http  gives an https address, similar to Cloudflare. Free accounts get one fixed address.

          
ZeroTier: like Tailscale, a private network between your devices.

          
Port forwarding: forward TCP and UDP port  on your home router to the main computer and share http://<your-public-ip>:/?k=…. Fastest, but some internet providers (and all cellular networks) don't allow it.

          
A cloud server (a small VPS): run edgemesh host --no-worker there so every device can always reach it.

          
For any of these, start the main computer with edgemesh host --public-url https://your-address so this page shows the right link. School networks can block some of them; Cloudflare and ngrok look like normal web traffic, so they get through most often.
